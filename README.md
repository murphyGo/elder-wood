# ELDERWOOD — 잊힌 숲의 부름

브라우저에서 플레이하는 한국어 싱글 플레이 3인칭 3D RPG입니다. Three.js와 TypeScript로 구현했으며, 캐릭터·동물·지형·건물은 프로젝트 코드로 직접 생성합니다.

![그린헤이븐 마을의 실제 게임 화면](docs/screenshots/village.png)

## 개선 계획

**v1.4 · 최종장 “하늘나무의 뿌리”와 메아리의 회랑**을 추가했습니다. 2막을 마친 뒤 마을의 엘리온에게 **F**로 말을 걸면 시작합니다. 과거 조사·동료와 길 복구·봉인의 운명 선택·최종 보스·귀환으로 이야기를 마무리하고, 엔딩 후에는 보스 재도전·연속 전투·공명 강화를 즐길 수 있습니다. [4차 최종장](docs/PHASE-4-FINALE.md), [3차 이야기 확장](docs/PHASE-3-STORY.md), [2차 그래픽](docs/PHASE-2-VISUALS.md), [1차 전투](docs/PHASE-1-COMBAT.md), [로드맵](docs/ROADMAP.md)에 범위와 검증을 정리했습니다.

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm install --registry=https://registry.npmjs.org
npm run dev
```

브라우저에서 http://127.0.0.1:5173 으로 접속하세요. WebGL 2를 지원하는 Chrome, Edge, Firefox, Safari에서 실행할 수 있습니다. 첫 화면의 **모험 시작하기**를 누르거나 장로 엘리온에게 다가가 **F**를 눌러 첫 퀘스트를 받습니다. **M**으로 지도를 열고 속삭임의 숲을 선택하면 사냥을 시작할 수 있습니다.

- 그린헤이븐 마을 → 속삭임의 숲 → 거인의 들판 → 잠긴 신전 → 용의 안식처

- 이야기·모험·숙련자 난이도 선택 (마을·항구의 Esc 메뉴 또는 안내서)
- 1막 프롤로그·4개 장·에필로그와 2막 검은 조수의 조사·준비·구조·퍼즐·보스·귀환 이야기
- 새벽물결 항구·별무덤 난파선·검은 조수의 제단을 더해 8개 지역, 새 NPC와 돌아온 선원들

스킬 위에 마우스를 올리거나 C 캐릭터 창을 열면 현재 무기의 피해·마력·재사용 시간을 확인할 수 있습니다. 활 R은 0.75초 뒤 자동 발사하며 회피·무기 교체로 취소됩니다. 취소해도 마력과 재사용 시간은 돌아오지 않고, 무기를 교체해도 각 스킬 슬롯의 남은 시간이 유지됩니다.

붉은 공격 예고 밖으로 피하고 몬스터의 공격 직후 빈틈을 노리세요. 상어가 사라지면 푸른 물결 밖으로 이동합니다. 용은 체력 70%에서 비행과 착지를 반복하고, 35%에서는 주변의 봉인을 F로 작동시켜야 8초간 공격할 수 있습니다. 터치 화면에서는 화면을 드래그해 시점을 돌리고 하단 이동·스킬·회피·대화 F 버튼을 사용합니다. X나 대상 고정 버튼은 가까운 몬스터를 계속 바라보고 공격하도록 고정합니다. Tab으로 고정 대상을 바꿀 수 있고, 대상 사망·거리 이탈·지역 이동 시 해제됩니다.

**Esc → 화면과 카메라 설정**에서 품질, 피격 시 흔들림, 활 조준 확대와 풍경의 움직임을 조절합니다. 움직임 줄이기를 사용하는 브라우저는 흔들림·활 확대·풍경 움직임을 끈 상태로 시작합니다. 품질은 몬스터 수나 전투 판정을 바꾸지 않습니다.

체력은 비전투 중 서서히 회복되고 마을에서 빠르게 회복됩니다. 이야기·숙련자 난이도는 적의 체력·공격 예고·피해·회복량도 바꾸며 경험치와 골드 보상은 동일합니다.

퀘스트 목표를 달성한 뒤 오른쪽 **보상 받고 이야기 이어가기**를 눌러야 다음 지역이 열립니다. 지역은 이야기 진행과 레벨 조건을 모두 충족해야 입장할 수 있습니다. 사망해도 레벨·장비·골드·퀘스트는 유지됩니다.

## 검은 조수 플레이 안내

1막을 마치고 그린헤이븐의 엘리온에게 편지를 받은 뒤 **M → 새벽물결 항구**로 이동합니다. 미라와 대화하고 그물·항해일지·검은 파편을 **F**로 조사하세요. 목표를 채우고 이야기 보상을 받으면 필수 제작 재료가 지급됩니다.

조수표를 읽고 도란의 작업대에서 **별빛 등불**을 제작합니다. 난파선에서는 남쪽 조수륜을 F로 작동해 썰물로 바꾸고 중앙 돌길을 건넙니다. 북쪽에도 조수륜이 있어 양쪽에서 다시 길을 열 수 있습니다. 주변 위험을 해소하고 선원 이안·세라를 구조한 뒤 미라에게 보고하세요.

등대 비문은 문양 순서의 단서를 줍니다. 틀려도 비용 없이 다시 시도할 수 있고, 순서와 현재 진행은 **L → 모험 일지**에서 확인합니다. 등대를 복구하고 보상을 받으면 Lv. 10부터 제단이 열립니다. 네리스는 돌진·잠행·꼬리 공격을 사용하고 체력 50%에서 두 번째 단계로 전환합니다. 잠행 중에는 공격이 닿지 않으므로 예고 밖으로 피하고 떠오른 뒤 공격하세요.

수호자의 기억을 읽고 미라에게 돌아오면 2막이 끝납니다. 조수의 심장 3개로 검·창·활을 각각 한 번 제작할 수 있고, 부족한 일반 재료는 항구에서 구입할 수 있습니다. 제작 무기도 해당 무기의 Q/E/R을 사용합니다. 숲의 리라 구조는 언제든 별도로 진행할 수 있습니다.

## 하늘나무와 엔딩 이후

2막 보상을 모두 받고 **M → 그린헤이븐 → 엘리온 F**에서 마지막 여정을 시작합니다. Lv. 12부터 기억의 유적으로 들어가 남쪽 기록 3개를 읽고 보상을 받으세요. 동행한 엘리온과 대화한 뒤 숲·바다의 공명석을 작동하면 중앙 뿌리 다리가 열립니다.

북쪽 서약석에서는 **함께 봉인을 지키기 / 별빛을 세계에 나누기** 중 한 길을 살펴보고 확정합니다. 선택은 저장되며 두 길 모두 같은 이야기 보상과 최종 결말을 제공합니다. 보상을 받고 Lv. 13부터 **별의 뿌리**로 들어갈 수 있습니다.

아스테르는 체력 65%에서 공명 보호막, 30%에서 마지막 폭풍 단계로 전환합니다. 2단계에서는 세 공명 장치 곁에서 **F**를 누르세요. 봉인을 지키면 보호막 해제 10초와 내 체력 20%의 보호막, 별빛을 나누면 해제 8초와 체력 18%·마력 15 회복을 얻습니다. 장치는 각각 12초 후 다시 사용할 수 있습니다. 해방 후 보상을 받고 씨앗을 읽은 뒤 엘리온에게 돌아가 마지막 보상을 받으면 엔딩입니다.

엔딩 후 **L 또는 M → 메아리의 회랑**에서 용·네리스·아스테르 재도전과 3연속 전투를 선택합니다. 마을이나 항구에서 입장하며, 1/2/3등급의 최소 레벨은 13/14/15입니다. 도전별 이전 등급 완료가 다음 등급을 엽니다. 최초 등급 완료는 인장 10/14/18개, 연속 전투는 추가 4개, 반복 완료는 2개를 줍니다. 같은 창의 **공명 강화**는 인장 8/14/20개로 무기 종류별 공격력 +4/+8/+12를 적용합니다. 아이템 고유 스킬 효과는 유지됩니다.

연속 전투는 남은 체력·마력·물약과 재사용 시간을 이어갑니다. 마지막 전투 후 **보상 받고 마을로**를 눌러야 보상을 받습니다. 지역 이동·사망·새로고침은 현재 도전과 미수령 보상을 종료합니다. 이전에 받은 인장·최고 등급·강화는 유지되며, 도전 중 몬스터는 별도 경험치·골드·재료나 이야기 처치 수를 주지 않습니다.

## 저장과 빌드

캐릭터 저장 키는 `elderwood-save-v4`, 별도의 화면 설정 키는 `elderwood-settings-v1`입니다. 화면 설정 초기화는 캐릭터 진행에 영향을 주지 않습니다. 이전 `elderwood-save-v1`·`elderwood-save-v2`·`elderwood-save-v3`의 진행을 자동으로 이전하고 원본은 유지합니다. v1에서는 숲의 치유가 E에서 T로 이동했다는 안내, v2에서는 항구, v3에서는 최종장 시작 안내를 받습니다. 조수·문양·조사·구조·제작품·재료, 최종장 선택과 엔딩, 도전 최고 등급·완료 횟수·인장·강화도 저장됩니다. 체력·마력과 재사용 시간도 보존하며 재접속만으로 회복되지 않습니다.

같은 브라우저의 같은 주소에 8초마다, 그리고 전투·구입·지역 이동·퀘스트 완료 시 저장됩니다. 다른 브라우저나 주소와 공유되지 않습니다. 손상된 기록은 자동으로 덮어쓰지 않고 복구 화면을 엽니다. 이전 기록 복구, 원본 보관 후 새 모험, 저장 없는 임시 플레이 중 선택할 수 있습니다. 저장 공간 접근·쓰기 실패는 작은 화면에서도 표시됩니다. **Esc → 새 게임**은 확인 후 현재 기록의 사본을 남기고 새 모험을 시작합니다.

```sh
npm run build
npm run preview
```

배포용 정적 파일은 `dist/`에 생성됩니다. 서버 API나 API 키는 필요하지 않습니다. 글꼴은 화면 표시를 막지 않는 방식으로 Google Fonts에서 내려받으며 접속이 불가능하면 시스템 글꼴로 표시됩니다. 초기 UI와 3D 엔진을 나누어 로딩 화면을 먼저 그립니다.

## 주요 파일

- `src/game/catalog.ts`: 무기 종류·아이템·스킬·난이도 정의
- `src/game/state.ts`: 성장·구입·이야기·저장 데이터 보정
- `src/game/persistence.ts`: 저장·이전·백업·복구
- `src/game/combat.ts`: 무기 전투·몬스터 AI·보스 단계·상태 효과
- `src/game/journey-data.ts` · `journey.ts`: 2막 대사·단계·조사·구조·퍼즐·제작 규칙
- `src/game/coast.ts`: 항구·난파선·제단, 조수 통로와 등대
- `src/journey-ui.ts`: 제작·기록·확장 지도와 목표 표시
- `src/game/finale-data.ts` · `finale.ts`: 최종장 기록·선택·진행·귀환
- `src/game/trial-data.ts` · `trials.ts`: 도전 등급·연속 전투·보상·공명 강화
- `src/game/skytree.ts`: 유적·뿌리·회랑과 선택별 마을 풍경
- `src/finale-ui.ts`: 선택·최종장 일지·도전·강화 메뉴
- `src/game/geometry.ts`: 이동과 공격 충돌 판정
- `src/game/actors.ts`: 캐릭터·동물·무기·갑옷 모델과 관절
- `src/game/animation.ts`: 무기별 자세와 동물별 동작
- `src/game/camera.ts`: 카메라 가림 검사와 추적
- `src/game/settings.ts`: 화면 품질과 접근성 관련 기본 설정
- `src/game/effects.ts`: 재사용하는 피격 입자와 접촉 그림자
- `src/game/models.ts` · `primitives.ts`: 나무·건물·기본 도형과 재질
- `src/game/world.ts`: 지형, 지역 환경, 충돌 영역, NPC·차원문 위치
- `src/game/engine.ts`: 렌더링·카메라·입력·공격 예고·동작·효과음과 전투 로직 연결
- `src/main.ts`: 한국어 HUD, 퀘스트·장비·상점·지도·대화 화면
- `src/style.css`: 데스크톱과 작은 화면용 UI

렌더러 구성은 [Three.js 공식 문서](https://threejs.org/manual/en/creating-a-scene.html)를 참고했습니다. 현재는 로컬 저장 기반의 싱글 플레이 게임이며, 온라인 멀티플레이나 계정 서버는 포함하지 않습니다.
