# ELDERWOOD — 잊힌 숲의 부름

브라우저에서 플레이하는 한국어 싱글 플레이 3인칭 3D RPG입니다. Three.js와 TypeScript로 구현했으며, 캐릭터·동물·지형·건물은 프로젝트 코드로 직접 생성합니다.

![그린헤이븐 마을의 실제 게임 화면](docs/screenshots/village.png)

## 개선 계획

**v1.2 · 그래픽과 조작감 개선**을 적용했습니다. 관절 애니메이션, 장비별 외형, 움직이는 풍경, 대상 고정과 화면 설정을 제공합니다. 구현·검증 내역은 [2차 그래픽 개선](docs/PHASE-2-VISUALS.md), 전투 규칙은 [1차 전투 개선](docs/PHASE-1-COMBAT.md), 다음 이야기 계획은 [로드맵](docs/ROADMAP.md)에 정리했습니다.

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm install --registry=https://registry.npmjs.org
npm run dev
```

브라우저에서 http://127.0.0.1:5173 으로 접속하세요. WebGL 2를 지원하는 Chrome, Edge, Firefox, Safari에서 실행할 수 있습니다. 첫 화면의 **모험 시작하기**를 누르거나 장로 엘리온에게 다가가 **F**를 눌러 첫 퀘스트를 받습니다. **M**으로 지도를 열고 속삭임의 숲을 선택하면 사냥을 시작할 수 있습니다.

## 게임에 들어 있는 것

- 관절 보행·무기별 자세와 공격, 얼굴·손·장비 외형, 동물별 체형과 목·꼬리·날개 동작
- 캐릭터를 따라가는 3인칭 카메라, 가림 대응, 대상 고정, 활 조준 확대, 터치 회전, 지형·건물 충돌과 점프·회피
- 바람에 흔들리는 풀과 잎, 흐르는 물결, 접촉 그림자·피격 입자, 자동·높음·보통·낮음 품질 설정
- 마을 NPC 대화·상점, 미니맵, 세계 지도와 지역 이동
- 그린헤이븐 마을 → 속삭임의 숲 → 거인의 들판 → 잠긴 신전 → 용의 안식처
- 다람쥐·토끼·소·말·하마·호랑이·상어·고대 용, 종류별 행동 패턴과 원·부채꼴·직선 공격 예고, 처치 보상과 일반 몬스터 재등장
- 경험치 획득과 레벨업, 레벨에 비례하는 체력·마력·공격력·방어력, 레벨이 높아질수록 증가하는 필요 경험치
- 검·창·활의 기본 무기 3개와 고유 효과 무기 6개, 무기별 장착 기억, 장비 비교·구입, 갑옷 3단계와 회복 물약
- 무기별 Q/E/R 스킬 9개와 공통 치유 T, 마력·재사용 시간·동작 취소, 화상·보호막·둔화·약화·연쇄 번개
- 용의 지상·비행·봉인 3단계 전투와 엔딩 이후 보상 없는 연습전
- 이야기·모험·숙련자 난이도 선택 (마을의 Esc 메뉴 또는 안내서)
- 프롤로그·4개 장·에필로그로 이어지는 완료 가능한 메인 이야기, 퀘스트 보상과 지역 해금
- 브라우저 자동 저장, 사망 후 마을 부활, 일시 정지, 효과음과 음소거, 전체 화면, 작은 화면용 메뉴와 터치 이동 버튼

## 조작

| 키 | 기능 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 오른쪽 버튼 / 터치 화면 드래그 | 카메라 회전 |
| 마우스 휠 | 확대·축소 |
| J / 마우스 왼쪽 버튼 | 기본 공격 · 누르면 연속 공격 |
| Tab | 공격 대상 변경 |
| X / 대상 고정 버튼 | 대상 고정·해제 |
| 1 / 2 / 3 | 검 / 창 / 활 |
| Q | 무기별 첫 기술 · Lv. 2 |
| E | 무기별 방어·이동 기술 · Lv. 3 |
| R | 무기별 대표 기술 · Lv. 5 |
| T | 공통 숲의 치유 · Lv. 3, MP 22, 10초 |
| Shift | 이동 방향으로 회피 · 1.8초 재사용 |
| Space | 점프 |
| F | NPC 대화 / 차원문 이용 / 용의 봉인 장치 작동 |
| H | 회복 물약 · 모험 기준 체력 60%, 4초 재사용 |
| C / I / M / L | 캐릭터 / 가방 / 세계 지도 / 퀘스트 일지 |
| Esc | 일시 정지 / 열린 창 닫기 |

| 무기 | Q | E | R |
| --- | --- | --- | --- |
| 검 | 삼연 베기 | 받아치기 | 회전 베기 |
| 창 | 돌진 찌르기 | 휩쓸기 | 관통 일격 |
| 활 | 다중 사격 | 도약 사격 | 충전 관통 사격 |

스킬 위에 마우스를 올리거나 C 캐릭터 창을 열면 현재 무기의 피해·마력·재사용 시간을 확인할 수 있습니다. 활 R은 0.75초 뒤 자동 발사하며 회피·무기 교체로 취소됩니다. 취소해도 마력과 재사용 시간은 돌아오지 않고, 무기를 교체해도 각 스킬 슬롯의 남은 시간이 유지됩니다.

붉은 공격 예고 밖으로 피하고 몬스터의 공격 직후 빈틈을 노리세요. 상어가 사라지면 푸른 물결 밖으로 이동합니다. 용은 체력 70%에서 비행과 착지를 반복하고, 35%에서는 주변의 봉인을 F로 작동시켜야 8초간 공격할 수 있습니다. 터치 화면에서는 화면을 드래그해 시점을 돌리고 하단 이동·스킬·회피·대화 F 버튼을 사용합니다. X나 대상 고정 버튼은 가까운 몬스터를 계속 바라보고 공격하도록 고정합니다. Tab으로 고정 대상을 바꿀 수 있고, 대상 사망·거리 이탈·지역 이동 시 해제됩니다.

**Esc → 화면과 카메라 설정**에서 품질, 피격 시 흔들림, 활 조준 확대와 풍경의 움직임을 조절합니다. 움직임 줄이기를 사용하는 브라우저는 흔들림·활 확대·풍경 움직임을 끈 상태로 시작합니다. 품질은 몬스터 수나 전투 판정을 바꾸지 않습니다.

체력은 비전투 중 서서히 회복되고 마을에서 빠르게 회복됩니다. 이야기·숙련자 난이도는 적의 체력·공격 예고·피해·회복량도 바꾸며 경험치와 골드 보상은 동일합니다.

퀘스트 목표를 달성한 뒤 오른쪽 **보상 받고 이야기 이어가기**를 눌러야 다음 지역이 열립니다. 지역은 이야기 진행과 레벨 조건을 모두 충족해야 입장할 수 있습니다. 사망해도 레벨·장비·골드·퀘스트는 유지됩니다.

## 저장과 빌드

캐릭터 저장 키는 `elderwood-save-v2`, 별도의 화면 설정 키는 `elderwood-settings-v1`입니다. 화면 설정 초기화는 캐릭터 진행에 영향을 주지 않습니다. 이전 `elderwood-save-v1`의 캐릭터 진행을 자동으로 이전하고 원본은 유지합니다. 기존 사용자는 **숲의 치유가 E에서 T로 이동했다는 안내**를 받습니다. 체력·마력과 재사용 시간도 보존하며 재접속만으로 회복되지 않습니다.

같은 브라우저의 같은 주소에 8초마다, 그리고 전투·구입·지역 이동·퀘스트 완료 시 저장됩니다. 다른 브라우저나 주소와 공유되지 않습니다. 손상된 기록은 자동으로 덮어쓰지 않고 복구 화면을 엽니다. 이전 기록 복구, 원본 보관 후 새 모험, 저장 없는 임시 플레이 중 선택할 수 있습니다. 저장 공간 접근·쓰기 실패는 작은 화면에서도 표시됩니다. **Esc → 새 게임**은 확인 후 현재 기록의 사본을 남기고 새 모험을 시작합니다.

```sh
npm run build
npm run preview
```

배포용 정적 파일은 `dist/`에 생성됩니다. 서버 API나 API 키는 필요하지 않습니다. 글꼴은 Google Fonts를 사용하며 접속이 불가능하면 시스템 글꼴로 표시됩니다.

## 검증

```sh
npm test
npm run test:e2e
```

- Vitest 71개: 화면 설정·저장 격리·카메라 충돌·명시적 조준·무기 방향·충전 취소 자세, 성장·퀘스트, 9개 스킬과 6개 장비 효과, 충돌·취소·보상 중복 방지, 난이도, 저장 이전·손상·쓰기 실패. 실제 지형과 전투 로직으로 세 무기 × 세 난이도 캠페인 9회 완주
- Playwright 16개: 품질 전환·설정 복원·GPU 지오메트리 증가 확인, 대상 고정·활 확대·터치 드래그, 실제 Chrome WebGL 화면, 이동·시점·무기 교체, 장비 6개 구입, 저장 복구와 난이도, 용의 3단계·에필로그, 모바일 배치·터치 치유·충전 취소·봉인 조작

브라우저 검증에는 설치된 Google Chrome을 사용합니다. 스크린샷과 실패 시 추적 기록은 `test-results/`에 생성됩니다. 테스트 준비용 게임 상태는 개발 서버에서만 `window.__ELDERWOOD__`로 확인할 수 있으며, 배포 빌드에서는 노출하지 않습니다.

## 주요 파일

- `src/game/catalog.ts`: 무기 종류·아이템·스킬·난이도 정의
- `src/game/state.ts`: 성장·구입·이야기·저장 데이터 보정
- `src/game/persistence.ts`: 저장·이전·백업·복구
- `src/game/combat.ts`: 무기 전투·몬스터 AI·보스 단계·상태 효과
- `src/game/geometry.ts`: 이동과 공격 충돌 판정
- `src/game/actors.ts`: 캐릭터·동물·무기·갑옷 모델과 관절
- `src/game/animation.ts`: 무기별 자세와 동물별 동작
- `src/game/camera.ts`: 카메라 가림 검사와 추적
- `src/game/settings.ts`: 화면 품질과 접근성 관련 기본 설정
- `src/game/effects.ts`: 재사용하는 피격 입자와 접촉 그림자
- `src/game/models.ts` · `primitives.ts`: 나무·건물·기본 도형과 재질
- `src/game/world.ts`: 지형, 지역 환경, 충돌 영역, NPC·차원문 위치
- `src/game/engine.ts`: 렌더링·카메라·입력·공격 예고·동작·효과음과 전투 로직 연결
- `src/main.ts`: 한국어 HUD, 퀘스트·장비·상점·지도·대화 화면
- `src/style.css`: 데스크톱과 작은 화면용 UI

렌더러 구성은 [Three.js 공식 문서](https://threejs.org/manual/en/creating-a-scene.html)를 참고했습니다. 현재는 로컬 저장 기반의 싱글 플레이 게임이며, 온라인 멀티플레이나 계정 서버는 포함하지 않습니다.
